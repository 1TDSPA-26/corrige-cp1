Formulário de contato Em paginas/contato.html, dentro de main, crie uma section com título e um form contendo fieldset. Insira um input text para nome, um input email para e-mail e um textarea para mensagem. Cada campo deve ter label associado por for e id correspondentes. Use placeholder nos três campos e um input submit com o texto “Enviar”. Não é necessário definir action nem criar processamento dos dados.

Fale com a equipe

Preencha os campos para registrar seu nome, seu e-mail e sua mensagem.
