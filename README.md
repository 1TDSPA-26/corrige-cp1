# 📝 Correção - Check-Point 1: Páginas Semânticas

Repositório oficial dedicado à correção, feedback e diretrizes de avaliação do **Check-Point 1 (CP1)** focado na construção de **Páginas Semânticas** utilizando HTML5 e conceitos fundamentais de estruturação web.

---

## 🎯 Objetivo

O principal objetivo deste repositório é fornecer uma base transparente, padronizada e acessível para a análise dos códigos desenvolvidos pelos alunos. Através deste espaço, os critérios de avaliação, os pontos de melhoria mais comuns e os gabaritos comentados são disponibilizados para apoiar o processo de aprendizagem contínua e garantir a correta aplicação da semântica web.

---

## 🗺️ ROADMAP

O fluxo de correção e acompanhamento do CP1 segue as etapas abaixo:

- [x] **Fase 1: Configuração do Ambiente e Padrões**
  - Definição dos critérios de avaliação (Rubrica de semântica, tags estruturais e acessibilidade).
  - Criação da estrutura base de testes.
- [ ] **Fase 2: Análise dos Trabalhos Entregues**
  - Verificação do uso correto de tags semânticas (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`).
  - Validação da hierarquia de títulos (`<h1>` a `<h6>`).
- [ ] **Fase 3: Emissão de Feedbacks**
  - Aplicação dos comentários de revisão por código.
  - Atribuição de notas e apontamentos de melhoria individual.
- [ ] **Fase 4: Publicação do Gabarito Comentado**
  - Disponibilização da resolução modelo com boas práticas de estruturação.
  - Encerramento do ciclo de correções do checkpoint.

---

## 🛠️ Tecnologias Avaliadas
- **HTML5** (Semântica estrutural)
- **Boas Práticas de Acessibilidade Básica** (Atributos `alt`, hierarquia limpa)
